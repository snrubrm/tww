# Contributing

This is a fork of [zeldaret/tww](https://github.com/zeldaret/tww) that allows AI-assisted decompilation. AI-generated code is accepted, provided you verify it: it must build (`ninja`), match in objdiff where claimed as matching, follow the [coding guidelines](/docs/coding_guidelines.md), and be reviewed for readability.

Check the [readme](/README.md) for details on how to get the repository set up, and the [decompiling guide](/docs/decompiling.md) for an explanation of the process of decompiling itself.
